## English Summary

### Models

Added MAI-Image-2.6, Wan 3.0, and MAI-Image-2.5-Pro; also updated FLUX 3's continuation limit, Veo 3.1 Lite's endpoint specifications, and Qwen Image 3.0 Pro's API access status. Qwen-Image-3.0 now has first-party API evidence but remains uncarded because its exact first-public date cannot be verified.

Page links: [MAI-Image-2.6](https://tobinzuo.github.io/AIGCDataHub/#model-mai-image-2-6) · [Wan 3.0](https://tobinzuo.github.io/AIGCDataHub/#model-wan-3-0) · [MAI-Image-2.5-Pro](https://tobinzuo.github.io/AIGCDataHub/#model-mai-image-2-5-pro)

Added CamWorldQA as unavailable/not released: the paper specifies 720 generated videos and subjective scores but provides no dataset repository or data license.

Page links: [CamWorldQA](https://tobinzuo.github.io/AIGCDataHub/#dataset-camworldqa)

### Data relations

No change; CamWorldQA is standalone evaluation data, and its six generator methods are construction subjects rather than evidence of model training-data use.

Page links: [View lineage](https://tobinzuo.github.io/AIGCDataHub/#lineage)

### Rankings

Six boards changed; MAI-Image-2.6, Wan 3.0, and MAI-Image-2.5-Pro now have first-party release evidence, while Grok Imagine Image 2.0, DreamImage 2.0, and MAGI-2 Preview remain evidence gaps. Arena image editing moves from required coverage to monitor because an exact ranked model lacks a verifiable release date; the gap remains visible without forcing an unsupported card.

Page links: [View industry rankings](https://tobinzuo.github.io/AIGCDataHub/#rankings)

### Monitoring

Reviewed all 70 machine candidates, 15 important revisions, six ranking changes, and the seven-day primary-source window; personal LoRAs, quantizations, mirrors, navigation links, and out-of-scope papers were not accepted.

Page links: [View source monitoring](https://tobinzuo.github.io/AIGCDataHub/#sources)

### Undisclosed

None of the three added models publishes a reproducible corpus inventory, scale, or processing recipe; CamWorldQA also omits source-video identity and rights, download timing, and a data license.

Page links: [MAI-Image-2.6 unknowns](https://tobinzuo.github.io/AIGCDataHub/#model-mai-image-2-6) · [Wan 3.0 unknowns](https://tobinzuo.github.io/AIGCDataHub/#model-wan-3-0) · [CamWorldQA unknowns](https://tobinzuo.github.io/AIGCDataHub/#dataset-camworldqa)

## 结论与落盘项

- **MAI-Image-2.6 — 已新增。** [Microsoft 官方发布](https://microsoft.ai/news/mai-image-2-6-launches-at-no-2-on-arena-ahead-of-google-meta-and-xai/)日期为 2026-08-10，并明确标注 2026-08-18 更新；更新后的访问形态为 MAI Playground 可用、Microsoft Foundry private preview。官方只确认文生图、图像编辑榜表现、多参考、更丰富 grounding，以及文字、人像、3D、商业与写实输出的改进，没有权重、公开 API 型号、模型许可、技术报告或模型专属训练数据披露。
- **Wan 3.0 — 已新增。** [官方生命周期表](https://help.aliyun.com/en/model-studio/newly-released-models)给出 2026-08-06 首发日与 `wan3.0-video`；[官方发布/API 页面](https://modelstudio.console.alibabacloud.com/model-releases/wan3.0-video)确认文本、图像、视频、音频、文档和网页参考，最长 30 秒、最高 1080P、原生音视频生成，以及需要申请批准的 API public preview。无公开权重、技术报告、参数规模或训练数据策略。
- **MAI-Image-2.5-Pro — 已补历史覆盖。** [Microsoft 官方发布](https://microsoft.ai/news/introducing-mai-image-2-5-pro-and-mai-voice-2-flash/)给出 2026-07-23 public preview；[Microsoft Foundry 文档](https://learn.microsoft.com/en-us/azure/foundry/foundry-models/how-to/use-foundry-models-mai-image)列出模型版本 `2026-06-19`，支持文生图与图像编辑。模型家族层面只披露“clean, traceable, enterprise-grade data”与不蒸馏第三方模型，没有点名数据集、规模、来源权利、清洗/去重或偏好数据。
- **Qwen-Image-3.0（非 Pro）— 事实更新，精确日期证据不足。** [官方 API 总览](https://help.aliyun.com/en/model-studio/qwen-image-api)目前明确列出 `qwen-image-3.0` 为 Recommended，属于同时支持生成和编辑的 3.0 系列，并称非 Pro 版本平衡质量和速度；[官方生命周期表](https://help.aliyun.com/en/model-studio/newly-released-models)仍只给 Pro 版 2026-07-21 日期。因此不能采用排行榜的“Jul 2026”反推精确 `released_at`；应等待官方发布日期或以仓库允许的未知日期表达处理。
- **CamWorldQA — 已新增 unavailable/not-released 数据卡。** [2026-08-19 论文](https://arxiv.org/abs/2608.18710)与[论文 HTML](https://arxiv.org/html/2608.18710v1)明确 720 条、832×480、15 fps、81 帧视频；20 条近静态真实源视频分动物/人物/物体/场景四类，经六种开源方法与六条相机轨迹生成。18 名受试者按 ITU-R BT.500 评分，剔除一人后形成 MOS，固定随机种子按 8:2 训练/测试划分。当前无官方代码、数据下载、数据许可或源视频身份/权利说明；arXiv 论文许可不是数据许可。

## Discovery 70 个候选处置

- **接受：** `CamWorldQA`，按尚未发布的评估数据集处理；不把相机控制视频的潜在 embodied 应用扩展为 Physical AI 分类。
- **已覆盖或导航入口：** 阿里云 `Image Generation` 是既有 Qwen/Wan 服务导航页；xAI 的 playground、图像生成/编辑、多图编辑、视频生成/编辑/续写、图生视频、参考生视频、Markdown 视图与旧版指南均是 `grok-imagine-image-2.0` 404 壳页面导出的导航链接，不是独立发布证据；`Imagine Video 1.5 with References` 已由既有卡覆盖。
- **第三方镜像、合并、格式转换、量化或 wrapper，不构成新基础模型：** 全部 HF 模型候选均为个人上传、镜像、LoRA、量化、格式转换、混合权重或薄 wrapper，包括 FLUX.2、Z-Image、Realistic Vision、Realesrgan、Anima、MiniMax H3、Krea 与 LTX 派生物；HF 元数据中的 license/weight 标签不能证明原始出版身份或独立训练资产。
- **证据不足的数据候选：** `ai-image-to-video-nsfw-prompts` 和 `dichi_video_generation` 没有可核验的官方出版组织、上游模型关系、数据来源权利与足够构建说明；不因有 size/license 元数据就收录。
- **超出维护范围：** UAV 视觉里程计、视频目标分割、具身视频综述、历史图像检索与 LVLM 幻觉缓解不是创意生成资产；其中 embodied AI 综述保持排除且不创建 Physical AI 分类。
- **CamWorldQA 的边界：** 论文提到 embodied intelligence 只是潜在应用之一；数据本体是相机控制生成视频质量评估，因此纳入生成视频评测范围，不创建具身/机器人场景。

## 15 个重要 revision 复核

- `cinedub-sa`：arXiv 页面内容哈希变化未带来新的数据下载、许可、样本规模或与 CineDub 的训练关系；维持现有 11 条数据关系和不可下载状态。
- `postercraft-public-corpora`：官方组织页仍仅列 Poster100K 与 Text-Render-2M；变化来自组织活动/页面内容，未发现新增语料、下载、许可或与 Emu3.5 的关系事实。
- `coinve-200k`：HF revision 在昨日首次收录后同日继续前移；现有一手论文所述约 200K、1.91 TB、CC-BY-NC-SA-4.0 和处理流水线没有得到可核验的新事实，不能只凭 SHA 更新卡片。
- `gemini-3-1-flash-lite-image`、`gemini-omni-flash`：官方 model card 仍分别继承/高层描述多模态数据；无新增可解析数据集、样本规模或混合比例。Gemini Omni Flash 只明确音频、视频、图像、文本训练数据及分层文本标注，不应推断具体来源。
- `gpt-image-1-5`：官方 API 页仍提供 `gpt-image-1.5` 与 `gpt-image-1.5-2025-12-16`，后者已 deprecated；没有新增模型训练数据或权重，未据此修改训练数据事实。
- `flux-2-max`：FLUX 2 Max 本身未出现新的权重、许可或数据策略；同一官方 release notes 的 2026-08-17 条目把 FLUX 3 视频续写请求上限改为 15 秒，已更新 FLUX 3 卡，文生视频、图生视频与 draft enhance 仍为 20 秒。
- `happyhorse-1-0`、`happyhorse-1-1`、`wan-2-6`：阿里云文档继续列既有 API 能力、地区与输出参数，未披露新的训练数据或技术报告；页面整体验证变化不等于对应模型事实变化。
- `wan-3-0`：新增监控后生命周期页哈希随页面更新而前移；官方仍只给发布日期、API 型号与服务能力，没有训练数据、权重或技术报告的新披露。
- `qwen-image-2`：现有 2.0 模型事实无变化，但同页首次为非 Pro `qwen-image-3.0` 提供明确 API 证据，不能错误并入 2.0 卡；同时将既有 Qwen Image 3.0 Pro 从 limited-preview 描述更新为当前 Recommended API 访问状态。
- `recraft-v4-1`：官方发布页仍只描述服务变体与能力，无新增训练数据、权重或技术报告。
- `dailymotion`、`pexels`：来源平台仍存在；页面或帮助中心 JSON 内容哈希前移不授予模型训练权利，也不改变既有 rights-review 边界。

- **Arena image edit：** `grok-imagine-image-2.0 (low)` 新进第 2，`mai-image-2.6-preview` 新进第 3。MAI-Image-2.6 有 Microsoft 官方发布；xAI 官方文档的公共模型配置已出现 exact `grok-imagine-image-2.0` 端点及 1K/2K low/medium 档，但独立页面仍呈 404 壳且没有精确发布日期，因此仅保留榜单缺口并加入持续监控。
