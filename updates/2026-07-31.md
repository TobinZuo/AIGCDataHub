## 接受：新增模型、数据集与数据策略

### MiniMax H3

- 官方在 2026-07-31 发布 `MiniMax-H3`，API 支持文生视频、首尾帧图生视频、图像/视频/音频参考生成与视频编辑，可生成 5–15 秒、最高 2K、24 FPS 视频。
- 访问状态记为 `api-only`。官方文案中的 open 不等于可下载权重：没有权重链接、模型许可证或技术报告，架构、参数量和全部训练数据字段保持未披露。
- 一手来源：[模型发布记录](https://platform.minimax.io/docs/release-notes/models)、[视频生成 API 指南](https://platform.minimax.io/docs/guides/video-generation?ready=6)、[模型总览](https://platform.minimax.io/docs/guides/models-intro)。

### ShadowDancer 与 Shadow Library

- 新增 `shadowdancer`，记录 SkyReels-V2-1.3B-I2V 初始化、32 维 latent action、cross-shadow prediction、flow matching 与 block-causal 长视频训练；代码按钮目前仍回到论文，未发现代码、权重或模型许可证。
- 新增不可下载的 `shadow-library`：论文表格各项近似值合计约 20.5M 帧，包括 SMPL-X/角色渲染、ManiSkill、第一/第三人称游戏、DL3DV、MiraData 与 Open X-Embodiment 子集。真实视频是 self-pair，用于维持视觉真实感；合成 shadow pair 用于动作不变性学习。
- 新增 `dl3dv-10k`、`miradata` 和 `open-x-embodiment` 三张公开上游卡及三条 `source-component` lineage，分别记录 Hugging Face 审批下载、自取 URL 元数据和 RLDS/云存储访问。游戏和模拟器内部源仍只保留在 Shadow Library 卡中，不虚构公共下载地址。
- 一手来源：[项目页](https://shadowdancer-1.github.io/)、[论文](https://arxiv.org/abs/2607.28362)、[DL3DV-10K](https://github.com/DL3DV-10K/Dataset)、[MiraData](https://huggingface.co/datasets/TencentARC/MiraData)、[Open X-Embodiment](https://github.com/google-deepmind/open_x_embodiment)。

### S-Avatar 与 NeRSemble

- 新增 `s-avatar`，按论文记录 ImageDream 多视图引导、LGM 风格 Gaussian 生成、FLAME 拟合和绑定模板；当前项目 GitHub 返回不可用，因此状态为 `announced`，不提供伪造代码或权重入口。
- 新增 `nersemble` 受控数据卡，官方提供申请表和下载客户端；记录 16 台同步 7.1 MP 相机、73 FPS、4,700+ 序列和 220+ 人头部数据。
- 模型只在 45 个 NeRSemble held-out subjects 上评测，关系标为 `evaluation`；论文没有声称用 NeRSemble 训练 S-Avatar。
- 一手来源：[S-Avatar 论文](https://arxiv.org/abs/2607.28164)、[NeRSemble 项目与申请入口](https://tobias-kirschstein.github.io/nersemble/)。

### UniGen-AR 与 800 万对训练混合

- 新增 `unigen-ar`，记录 Qwen2.5-VL 条件编码、Infinity bitwise VQ-VAE/VAR 解码、两阶段训练（projector 2 epochs；全模型 100K steps）和固定 512×512 输出。
- 新增五张公开训练来源卡：`laion-coco-aesthetic`（论文使用 4.1M）、`graph200k`（205K source examples 的多任务视图）、`refcoco`（论文报告 320K transformed pairs）、`omniedit-filtered-1-2m`（约 1.2M 原始编辑对及重叠指令视图）、`stylebooth`（11K）。
- 把 GenEval、Emu-Edit、NYUv2、LOL、GoPro 和 Rain-13K 收敛为 `unigen-ar-evaluation-suite` 关系卡，明确没有合并下载，需按六个上游入口和许可分别获取；它们不计入论文所述 8M 训练对。
- 数据策略记录为 Graph200K 的模型标注和合成退化、OmniEdit 的 specialist supervision 与 MLLM 筛选、T2I batch probability 0.25；重叠 task view 不按独立 source image 重复计数。
- 一手来源：[论文及训练数据附录](https://arxiv.org/abs/2607.24157)、[Graph200K](https://huggingface.co/datasets/VisualCloze/Graph200K)、[OmniEdit](https://huggingface.co/datasets/TIGER-Lab/OmniEdit-Filtered-1.2M)、[StyleBooth](https://huggingface.co/scepter-studio/stylebooth/tree/main/datasets)。论文所给项目页在本次核验时返回 404，因此不把它当作可用制品入口。

### ReMind 5B 与 ReMind1M

- 新增 `remind`：Applied Intuition Research 于 2026-07-30/31 公开完整 5B generator、rank-128 SF-DMD EMA adapter 和推理代码；权重为 CC-BY-NC-4.0，Wan2.2-TI2V-5B 上游条款继续适用，1.3B 版本仍未发布。
- 新增公开 `remind1m`：557 GB、1,419,331 行，其中 Helios physics-filtered 1,027,329、pair-fixed InSpatio 265,945、Kubric camera augmentation 126,057；记录生产 `caption_v2`、camera NPZ 和审计字段。InSpatio 必须使用修复 8×32 shard-export transpose 的 pair-fixed manifest。
- 新增不可下载的 `remind-pexels-dynamic-clips`：论文明确用 100+ 动态事件 taxonomy 检索 Pexels，并由 Qwen3-VL 过滤事件、切镜和时空占比，但没有发布 URL 清单、保留量或数据专属许可。
- 关系另行指向既有 `openvid-1m` 与本次新增 `dl3dv-10k`；STEVO-Bench、VBench 保持 evaluation-only，不写入训练关系。
- 一手来源：[官方模型与权重](https://huggingface.co/AppliedIntuitionResearch/ReMind)、[ReMind1M](https://huggingface.co/datasets/AppliedIntuitionResearch/ReMind1M)、[官方代码](https://github.com/Applied-Intuition-Open-Source/ReMind)、[论文](https://arxiv.org/abs/2605.25333)。
