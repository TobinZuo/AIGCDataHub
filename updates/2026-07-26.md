Review window: 2026-07-12 through 2026-07-26, with one earlier July release
accepted because it introduced a new model family and a material data-strategy
disclosure.

## Already covered

- FLUX 3, released 2026-07-23, was already tracked with its joint media and
  action-data strategy.

## Scope decisions

- GPT-5.6 Sol was not added: the current catalog excludes text-only or general
  reasoning releases unless an official source discloses a material media-
  generation or physical-AI data strategy.
- Product capability statements were not converted into training-data claims.
  In particular, Muse Video's native audio capability is not treated as proof
  of any named audio corpus.

## Schema change

- Added `product-only` model access for releases available in a consumer
  product but not as weights or an API.
- Added `unknown` as a training-stage modality so cards do not need to infer
  source modalities from model outputs.

## Coverage expansion: audio and 3D

This review also closes two catalog-level modality gaps with primary-source
cards and a directly linked model strategy.

| Item | Decision | Data-strategy result | Primary evidence |
|---|---|---|---|
| SoundAtlas | Added verified audio dataset card | About 470K AudioSet/VGGSound-derived pairs built with audiovisual routing, agentic captioning, and multimodal consistency filtering. | [Project](https://omni2sound.github.io/) · [paper](https://arxiv.org/abs/2601.02731) |
| Omni2Sound | Added verified model card | Names eight pretraining corpora, then SoundAtlas multitask fine-tuning and an off-screen/text-dropout robustness stage; exact mixture ratios remain unknown. | [Model](https://huggingface.co/Dalision/Omni2Sound) · [repository](https://github.com/omni2sound/Omni2Sound) |
| Cap3D | Added verified 3D dataset card | Current release contains 1,604,291 captions plus derived 3D representations for large subsets; object-level licenses remain binding. | [Dataset](https://huggingface.co/datasets/tiange/Cap3D) · [repository](https://github.com/crockwell/Cap3D) |
| Objaverse-XL | Added partial 3D dataset card | More than 10M deduplicated objects and official acquisition tooling are public, but source availability and per-object rights vary. | [Repository](https://github.com/allenai/objaverse-xl) · [paper](https://arxiv.org/abs/2307.05663) |

The dataset schema now represents `audio` and `3d` modalities plus audio
quality, audiovisual alignment, geometry quality, and multi-view consistency.

## Release-date normalization

All 14 dataset cards now record a maintaining organization, an exact-version
`released_at` date, and a primary `release_date_source`. Generated README and
site catalogs sort datasets newest-first instead of grouping them alphabetically
by modality.

Version-specific corrections include Re-LAION-5B's 2024-08-30 official release,
Pick-a-Pic v2's 2023-09-25 repository introduction, FineVideo's 2024-09-23
official launch, and WebVid-10M's 2022-05-13 scale-up release. `last_verified`
continues to mean evidence review time and is not used as a substitute for the
dataset's publication date.

## Complete Omni2Sound pretraining lineage

All ten datasets named by the Omni2Sound report now resolve to catalog cards.
This closes the remaining six plain-text references without pretending that a
current public release is necessarily the exact training snapshot.

| Dataset | Catalog result | Material boundary |
|---|---|---|
| Clotho 2.1 | Added partial card for 6,974 clips and 34,870 human captions | The model report says only `Clotho`; captions are non-commercial and media licenses are per Freesound item. |
| AudioSet | Added partial card for 2,084,320 labelled segments | Google distributes URL annotations and features, not raw YouTube audio. |
| VGGSound | Added partial card for 210K+ audiovisual clips | Availability depends on a later YouTube fetch and original owners retain media copyright. |
| FSD50K | Added verified card for 51,197 clips and 108.3 hours | Dataset curation is CC BY, but 7,818 clips use CC-BY-NC or CC Sampling+ terms. |
| Million Song Dataset | Added partial feature/metadata card for one million tracks | The official dataset contains no raw audio, so Omni2Sound's actual ingestion path remains unknown. |
| FMA | Added verified card for 106,574 tracks and 343 days | Per-track Creative Commons terms determine attribution and commercial eligibility. |

The model's directory coverage is now 10/10. Mixture weights, per-dataset sample
counts, media snapshots, and the exact use of feature-only MSD data remain
explicit unknowns rather than inferred facts.
