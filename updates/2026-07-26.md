## Scope decisions

- GPT-5.6 Sol was not added: the current catalog excludes text-only or general
  reasoning releases unless an official source discloses a material media-
  generation or physical-AI data strategy.
- Product capability statements were not converted into training-data claims.
  In particular, Muse Video's native audio capability is not treated as proof
  of any named audio corpus.

## Schema change

- Added `product-only` model access for releases available in a consumer
  product but not as weights or an API.
- Added `unknown` as a training-stage modality so cards do not need to infer
  source modalities from model outputs.

## Release-date normalization

All 14 dataset cards now record a maintaining organization, an exact-version
`released_at` date, and a primary `release_date_source`. Generated README and
site catalogs sort datasets newest-first instead of grouping them alphabetically
by modality.

Version-specific corrections include Re-LAION-5B's 2024-08-30 official release,
Pick-a-Pic v2's 2023-09-25 repository introduction, FineVideo's 2024-09-23
official launch, and WebVid-10M's 2022-05-13 scale-up release. `last_verified`
continues to mean evidence review time and is not used as a substitute for the
dataset's publication date.

## Source-bound strategy comparison

The generated site payload now carries a deterministic `strategy_profile` for
every model. It preserves stage order and first-seen source-type and operation
order, then counts declared data references, catalog-linked datasets,
scale-disclosed stages, total stages, and explicit unknowns. These fields are
computed from the reviewed YAML cards; they do not add claims to the cards.

The data-strategy view uses that profile for a same-scenario comparison matrix.
Users first choose image generation, video generation, digital humans, video
localization, or Try-On, then compare disclosure level, training stages, source
types, dataset lineage, scale disclosure, and unknown counts. The matrix does
not rank models or turn missing disclosure into a synthetic quality score.

## Important dataset revision monitoring

The weekly scanner now watches 50 official sources. Ten are first-party
Hugging Face dataset API endpoints for high-value image-text, video, dubbing,
Try-On, audio, 3D, and evaluation corpora. Their stable revision is the
pair of `lastModified` and repository commit SHA; after the first reviewed
baseline, any change opens the same triage Issue as a new model candidate.

unauthenticated GitHub Actions context, so it is not used as a revision probe.

dataset API. Access and license review for Pick-a-Pic v2 still follows the
90-day freshness policy.

## Canonical model–dataset relationship index

Model cards remain the only editable source of a model-to-dataset relationship:
each named reference links to a reviewed dataset card through `catalog_id`.
Site generation now emits a normalized relation index and symmetric model and
dataset backlinks. The current 20 model and 29 dataset cards produce 16
navigable relationships, including GraphVid ↔ GraphVid-Bench, Fit-VTO ↔
FIT-VTO-100K, and JUST-DUB-IT ↔ Audiovisual Translation Dubbing Dataset.

Dataset `evidence.used_by` is deliberately separate: it records what an upstream
source says, while only a model card's `catalog_id` creates a canonical relation.
