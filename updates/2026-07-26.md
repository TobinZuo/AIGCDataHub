## Source-bound strategy comparison

The generated site payload now carries a deterministic `strategy_profile` for
every model. It preserves stage order and first-seen source-type and operation
order, then counts declared data references, catalog-linked datasets,
scale-disclosed stages, total stages, and explicit unknowns. These fields are
computed from the reviewed YAML cards; they do not add claims to the cards.

The data-strategy view uses that profile for a same-scenario comparison matrix.
Users first choose image generation, video generation, digital humans, video
localization, or Try-On, then compare disclosure level, training stages, source
types, dataset lineage, scale disclosure, and unknown counts. The matrix does
not rank models or turn missing disclosure into a synthetic quality score.

## Canonical model-dataset and dataset-lineage indexes

Model cards remain the only editable source of a model-to-dataset relationship:
each named reference links to a reviewed dataset card through `catalog_id`.
Site generation now emits a normalized relation index and symmetric model and
dataset backlinks. The current 26 model and 44 dataset cards produce 23
navigable relationships, including GraphVid ↔ GraphVid-Bench, Fit-VTO ↔

↔ OpenVE-3M / OpenVE-Bench.

Dataset cards can now declare a reviewed `derived_from` edge with an upstream
catalog ID, relationship type, contribution, and notes. Validation rejects
unknown parents, duplicate edges, self-links, and cycles. Site generation emits
twelve dataset-to-dataset relationships plus symmetric upstream and downstream
backlinks. Initial coverage includes OpenHumanVid and Panda-70M → TalkVerse,
OpenHumanVid → OpenHumanVid-Talking, AudioSet and VGGSound → SoundAtlas,

MVHumanNet → MVHumanNet++, and OpenVE-3M → OpenVE-Bench.

Dataset `evidence.used_by` is deliberately separate: it records what an upstream
source says, while only a model card's `catalog_id` creates a canonical relation.

## Impact-aware monitoring and relationship view

The site now has a dedicated **关系图谱** view rather than exposing lineage only
inside expanded cards. Model-to-dataset rows preserve role, availability, and
scale; dataset-to-dataset rows preserve transformation type and upstream
contribution. Every endpoint opens its corresponding card, and search,
modality, and scenario filters apply to both relationship types.

The twenty-five important dataset revision probes now carry a canonical dataset
ID and an explicit priority. Nineteen application-critical datasets include
VGGSound-Omni,
Audiovisual Translation Dubbing Dataset, FIT-VTO-100K, WavCaps, VITON-HD-edit,
TripVVT-10K, TalkVerse, OpenHumanVid-Talking, OpenHumanVid, Panda-70M,
Koala-36M, FreeMan, MVHumanNet, MVHumanNet++, CommonCatalog, Fine-T2I, GPIC,

When one changes, the discovery Issue includes its dataset ID, every downstream

either a direct model reference or that downstream lineage. The generated site
also displays the monitoring tier and links to the exact revision probe, while
unmonitored datasets remain explicitly unmarked.
