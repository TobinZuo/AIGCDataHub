## 本次实质变化

- [Qwen Image 3.0 Pro](https://help.aliyun.com/en/model-studio/qwen-image-generation-and-editing-api-reference)：按阿里云 2026-07-21 邀测记录建卡；支持文生图及 1–3 张参考图编辑、最高 2048×2048、最多 6 个输出，但无权重、技术报告或训练数据披露。
- [JoyAI-Video-Edit](https://github.com/jd-opensource/JoyAI-Video-Edit)：新增 16B 开源权重模型；记录 4.3B/793M 图片预训练、370M/108M 视频预训练、30M SFT、6.5M continual training、3.2M 图片编辑及 5.3M+1.1M 视频编辑对等官方阶段规模。
- [QuerySplat](https://huggingface.co/inspatio/querysplat)：新增 Apache-2.0 的 1B checkpoint；只以 DL3DV-10K 训练，DL3DV-Evaluation 严格作为独立评测集。
- [InfiniSplat](https://huggingface.co/PLUS-WAVE/InfiniSplat)：新增 RGB/LiDAR 两个官方 checkpoint；只以 Hypersim 训练，ETH3D、ScanNet++、Tanks and Temples 与 DL3DV 全部保持 evaluation 关系。
- [LeapTalk](https://huggingface.co/z-rx/leaptalk)：新增 Apache-2.0 权重；以 VividHead 进行 10K 步单步桥接蒸馏，HDTF 与 CelebV-HQ 只用于 80 条视频评测样本。
- [FLUX 3 Video](https://bfl.ai/blog/flux-3-video)：更新为 BFL API 正式可用，记录 720p/1080p、最长 20 秒、原生音频、关键帧条件及最长 4 秒音视频续写；FLUX 3 Image 与 Dev 权重仍未发布。
- [Veo 3.1 Lite](https://ai.google.dev/gemini-api/docs/models/veo-3.1-lite-generate-preview)：补充编辑和带音频视频输出；官方当前明确不支持 4K 与视频续写。
- [Poly Haven](https://polyhaven.com/license)：素材仍为 CC0，但网站当前条款要求未经明示许可不得抓取或数据挖掘；ID-V2V 的具体 HDRI 清单仍未发布。

## 下载、许可与访问条件

- 直接权重：JoyAI-Video-Edit、QuerySplat、InfiniSplat、LeapTalk 均指向官方 Hugging Face 文件；Qwen Image 3.0 Pro 与 FLUX 3 Video 仅 API，无权重链接。
- Hypersim 官方脚本可下载约 1.9TB 渲染数据，公开版 74,619 张图；源三角网格依赖另购 Evermotion 资产，不能把渲染数据许可自动外推至源资产。
- DL3DV-Evaluation 提供 55 个场景、约 500GB 的门控下载脚本，需 Hugging Face 登录；其场景与 DL3DV-10K 不重叠。
- ETH3D 为 CC BY-NC-SA 4.0；ScanNet++ 需签署仅限非商业研究/教育的申请条款且禁止向未签署者分享。
- Tanks and Temples 页面一处称 CC BY 4.0，另一处又限制非商业研究并禁止第三方分享，因此商业与再分发均标记 review-required。
- VividHead 直接提供十个归档和 metadata，但 Hugging Face frontmatter 的 Apache-2.0 与正文的 CC BY 4.0/研究非商业用途表述冲突，媒体权利不能视为已澄清。
- LongV2VBench 没有官方文件、许可或下载链接；只记录论文事实，不生成占位下载。

## 数据策略与仍未披露项

- JoyAI 对图片执行锐度/质量/黑边过滤和感知/嵌入去重；视频执行质量、美学、运动、相机稳定性与时序有效性过滤，去除模糊、旋转、幻灯片和损坏样本，并通过聚类降采高频概念、保留长尾与运动。
- JoyAI 的编辑对由两条合成管线生成：关键帧编辑后用 I2V 传播，或共享 latent 生成配对视频；随后筛选编辑正确性、内容保持与时序一致性，并由 MLLM 重写指令。源媒体身份、许可、地区、语言、精确阈值和混合权重仍未披露。
- QuerySplat 报告 300K 基础训练步及逐级扩展到 8192 queries 的训练；未公开 DL3DV 精确场景哈希，冻结 VGGT-Omega 的继承训练数据也未补齐。
- InfiniSplat 报告 Hypersim 单 context/三 target、100K 步、8×H20；DepthPro、InfiniDepth、DINOv3 等冻结编码器的继承语料仍未知。
- LeapTalk 披露 VividHead 与 10K 蒸馏步，但未披露精确人物/片段清单、许可冲突处理、语言权重与 80 条评测视频 ID；Wan2.1/Wav2Vec 继承数据也未完整重述。
