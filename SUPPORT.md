# Support

- Use [GitHub Discussions](https://github.com/TobinZuo/AIGCDataHub/discussions)
  for questions, usage ideas, and broader data-strategy conversations.
- Use the [model issue form](https://github.com/TobinZuo/AIGCDataHub/issues/new?template=model.yml)
  to propose or correct a model card.
- Use the [dataset issue form](https://github.com/TobinZuo/AIGCDataHub/issues/new?template=dataset.yml)
  to propose or correct a dataset card.
- Follow [SECURITY.md](SECURITY.md) for private security reports.

Please include a primary source whenever a question depends on release dates,
access, licensing, training data, or model-data relationships.
